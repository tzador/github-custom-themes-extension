# Bundled fonts

Web-friendly (`woff2`) font assets for the GitHub custom themes extension.
Every family ships with its license file in the same folder — keep them together
when redistributing (required by OFL/Apache/MIT).

Files downloaded from Google Fonts' CDN are **variable fonts, latin subset**
(small, covers English/Western European text; other scripts fall back to system
fonts). Files from official GitHub repos are full builds.

## License notes

- **OFL 1.1**: bundle/redistribute/embed freely (including commercially); keep the
  license file with the fonts; you may not sell the font files by themselves.
- **MIT + Bitstream Vera (Hack)**: same practical effect — attribution + license text.
- **UFL 1.0 (Ubuntu Sans Mono)**: same practical effect — redistribute freely with the
  licence file; derivatives must be renamed.
- No license requires attribution in the extension UI.
